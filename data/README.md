# Исходные данные для тестового задания

5 ноября добавлены два товара без незаполненных полей: Testo 608-H1 и 608-H2. Их источники и решения описаны в [additional-products.md](additional-products.md). Ниже сохранён отчёт о первоначальной паре товаров и этапе подготовки данных.

Этап 1 выполнен 4 ноября 2026 года: подготовлены два входных примера для будущего генератора. Это исходные факты, а не результаты генерации SEO-текстов. API модели пока не вызывается.

## Файлы

- `products/testo-0560-1109.json` — поверхностный термометр, предложение `73083`, артикул `0560 1109`.
- `products/appa-61.json` — мультиметр, предложение `70513`, код магазина `3761`.
- `sources/selected-offers.xml` — только два выбранных элемента исходного фида с исходной датой каталога; это выборка, а не полный фид.
- `sources/feed-manifest.json` — URL, дата каталога, хеш исходного скачанного файла и хеш выборки.

## Формат

Основные поля соответствуют заданию: `name`, `manufacturer`, `specs`, `description`. К ним добавлены идентификаторы, источники и замечания к качеству данных.

- `specs`: отображение «характеристика → строка или null». Диапазоны, единицы и условия сохраняются вместе со значением.
- `null`: значение не установлено или источники расходятся. Это не «нет функции» и не нулевое значение. Интерфейс должен показывать «данных нет» либо «требует уточнения» с учётом `data_issues`.
- `description`: краткий пересказ подтверждённого назначения и принципов представления характеристик своими словами, не рекламный текст.
- `sources`: проверенные ссылки, дата проверки, конкретный раздел и список полей `supports` в формате JSON Pointer. Ссылки могут подтверждать одно поле совместно. `checked_on` — дата нашей проверки, а не публикации документа.
- `data_issues`: поле, причина отсутствия значения, источники и вопрос менеджеру. Альтернативные значения из замечаний нельзя использовать как подтверждённые характеристики.
- `manufacturer`: значение бренда/производителя из `vendor` фида; юридическое наименование изготовителя не устанавливалось.

Названия нормализованы для чтения; исходные названия сохранены в XML. Единицы у каждого предела APPA прописаны явно. Перечень пределов не превращён в непрерывный диапазон с первым пределом в качестве минимально измеримого значения. Формулы погрешности напряжения APPA раскрыты с сохранением процентной составляющей и единиц младшего разряда.

## Подготовка и сверка

Фид содержит идентификацию и коммерческие сведения, но не описание и технические параметры измерений. Характеристики добавлены отдельно из карточек и документации, указанной в `sources`. Цена и наличие остаются только в исходной XML-выборке: они не являются стабильными техническими фактами для генерации.

Для Testo скачано руководство по ссылке из карточки, прочитан текст, визуально проверены страницы 4 и 6. Приняты только сведения, относящиеся к 0560 1109, и применимые общие параметры. Применение проникающих термометров и IP67 другой модели не перенесены. Размеры и масса упаковки не использованы как размеры и масса прибора.

Для APPA просмотрены индексированная карточка магазина и текст руководства/технического листа на сайте ПРИСТ. Прямое открытие карточки и получение изображений PDF не сработали; загрузка технического листа завершилась таймаутом. Поэтому визуальная сверка таблиц APPA не заявляется. Совпадающие параметры сверены по текстам; неоднозначные оставлены незаполненными. Привязка редакции руководства к конкретной поставке не установлена.

## Найденные расхождения

| Прибор и поле | Решение |
| --- | --- |
| Testo: погрешность за пределами −30…+250 °C | В карточке ±2 °C, в руководстве ±2% от измеренного значения. `null`, требуется уточнение. |
| Testo: IP | Не установлена для 0560 1109. `null`; IP67 соседней модели не переносится. |
| APPA: ёмкость | Карточка заявляет функцию, руководство исключает APPA 61. `null`. |
| APPA: True RMS | Карточка и документация расходятся. `null`, функция не включена в описание. |
| APPA: погрешность сопротивления | Различаются формулы и привязка к пределам. `null`. |
| APPA: артикул производителя | В фиде пустой. `null`, код магазина сохранён отдельно. |

При сверке APPA также обнаружены различия размеров, массы, порога прозвонки и максимального индицируемого числа между карточкой и руководством. Эти необязательные для примера поля не включены. Гарантия, сертификация и комплект поставки не утверждаются в примерах. Набор характеристик намеренно не исчерпывающий.

## Использование на следующих этапах

Генератор должен получать подтверждённые значения `name`, `manufacturer`, `specs` и `description`. Замечания передаются отдельно как ограничения; конфликтующие альтернативы не становятся фактами. При `null` сервис возвращает пояснение и вопрос менеджеру. Таблица характеристик строится из исходного JSON без изменения числовых значений моделью.

При подготовке финальной демонстрации потребуется ручная проверка технических утверждений в сгенерированном тексте. Эти JSON позволяют демонстрировать полезный черновик даже при наличии явно обозначенных пробелов, но не заменяют согласование спорных характеристик перед публикацией.

Полные PDF и изображения страниц находятся во временной папке `tmp/`, исключённой из Git. В наборе сохранены ссылки и собственные нормализованные записи фактов; исходные руководства не дублируются в репозитории.
