Здравствуйте!

Подготовил тестовое задание — локальный AI-помощник для создания черновиков карточек контрольно-измерительных приборов для B2B-магазина.

Репозиторий: https://github.com/Choco-init/union_b2b

Реализованы ввод и загрузка JSON, генерация через OpenAI GPT-6 Luna, SEO-заголовок, описание 800–1200 символов, таблица характеристик, поисковые запросы и блок для менеджера. Результат можно скопировать или скачать в JSON/Markdown. Приложение обрабатывает некорректные данные, ошибки API, пропуски и явно указанные противоречия в источниках.

Технические значения подставляются из исходных фактов, таблица строится программно. После генерации проверяются формат и длина, предусмотрена одна попытка исправления. Для длинных описаний доступно консервативное сокращение по целым предложениям с повторной проверкой. Свободный текст всё равно требует редакторского просмотра.

В README есть инструкция запуска и готовый JSON для копирования. Для быстрой демонстрации рекомендую Testo 608-H1 и 608-H2: в выбранном наборе данных нет незаполненных полей. Ещё два примера показывают обработку пропусков и расхождений между карточками магазина и документацией. Сохранённые результаты доступны без API-ключа; новая генерация требует собственного ключа.

Основная сложность — достоверность технических сведений и соблюдение ограничений длины. Найденные расхождения сохранены явно, спорные значения не подставляются как подтверждённые. Ограничения и возможные улучшения описаны в README. Локально прошли 28 тестов; в репозитории настроен их запуск через GitHub Actions.
