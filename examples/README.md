# Примеры генерации

Результаты реальных вызовов OpenAI от 4–5 ноября 2026 года: `gpt-6-luna`, reasoning `low`, промпт `luna-product-v3`. У новых 608-H1/H2 выполнена редакторская правка повторов без добавления технических сведений; изменения отмечены в JSON (`editorial_review`).

| Товар | Символов в описании | Запросов | Оценка стоимости, USD |
| --- | ---: | ---: | ---: |
| APPA 61 | 1045 | 1 | 0.00043970 |
| Testo 0560 1109 | 1135 | 2 | 0.00071085 |
| Testo 608-H1 | 889 | 2 | 0.00087700 |
| Testo 608-H2 | 839 | 2 | 0.00051184 |

В `generated/` лежат JSON с метаданными и Markdown для просмотра. Все четыре результата прошли проверки формата и длины. Таблицы построены из исходных данных без участия модели; числовые факты подставлены из входа целиком. Ручной просмотр не выявил заявлений о спорных True RMS/ёмкости APPA или неизвестной защите IP Testo.

Тексты остаются черновиками: в них встречаются общие фразы и повторы. Статус `ready` означает прохождение автоматических проверок, а не готовность к публикации без редактора. У APPA сохранены четыре замечания к данным, у Testo 0560 1109 — два; у 608-H1/H2 нет незаполненных полей в выбранном наборе. Четыре товара не составляют репрезентативной оценки модели.

Стоимость рассчитана по usage API, включает повторную попытку Testo и не включает предыдущие отладочные прогоны. Это оценка токенов, а не итоговый счёт провайдера. Подробности расчёта — в основном README.

Для новых товаров в таблице указан расход успешных генераций. Предыдущий прогон H2 завершился превышением длины (1272 символа), его дополнительный расход составил $0.00077208. Общая оценка трёх генераций новой пары — $0.00216092. Редакторская правка локальная, без API.

В приложении кнопка «Показать сохранённый пример» открывает эти результаты без вызова API, если исходные данные совпадают.
