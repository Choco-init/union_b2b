# Поверхностный мини\-термометр Testo 0560 1109

*Черновик для проверки контент-менеджером.*

## SEO-описание

Поверхностный мини\-термометр Testo 0560 1109 измеряет температуру поверхности при контакте измерительного наконечника с объектом. Расширенный наконечник предназначен для поверхностных измерений, а результат отображается на однострочном ЖК\-дисплее. Термометр рассчитан на задачи, в которых важно получить показание непосредственно с поверхности, а не измерить температуру на расстоянии. Контактный принцип следует учитывать при выборе способа контроля и организации измерений.<br><br>Диапазон измерений: −50…\+300 °C. Погрешность при −30…\+250 °C: ±1 °C. Указанные характеристики позволяют оценить, подходит ли прибор для ожидаемых температур и требуемой точности в условиях, для которых приведены данные. Погрешность зависит от участка диапазона, поэтому приведённое значение нельзя автоматически переносить на весь диапазон измерений. Прибор может использоваться для контроля температуры поверхностей в пределах заявленных параметров; выбор модели для конкретной задачи следует соотнести с температурой объекта и условиями контакта наконечника с поверхностью. Показание считывается с дисплея, а само измерение выполняется контактным способом.
